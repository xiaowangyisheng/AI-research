# scientific-graphical-abstract 简要说明

这个 skill 用于把科研参照图、手绘示意图或 AI 生成的机制图，整理成可在 Adobe Illustrator 中修改的 SVG。适用于论文 graphical abstract、机制示意图和实验设计图。

## 推荐流程

**先准备图 → 选择 GPT-6 astra／High → 调用 skill → 生成可编辑 SVG → 在 Illustrator 中修改。**

1. 找一张参照图，或准备已经画好／生成的示意图，尽量使用清晰原图。
2. 在运行环境中选择 **GPT-6 astra**，推理强度设为 **High（高）**。这是本工作流的运行要求；安装 skill 不会自动切换模型。
3. 上传图片并说明用途：已有满意图就“保留原图转 SVG”；只有风格参照则附上摘要，说明“参照重画后转 SVG”。
4. 调用下方示例。skill 会核对标签与箭头、重建可编辑文字、转换图形路径，并检查实际渲染效果。
5. 在 Illustrator 中直接打开 SVG，修改文字、路径和颜色，按需另存为 `.ai`。

## 可复制的调用语句

**已有示意图，只转换：**

> 使用 $scientific-graphical-abstract，把附件图转换为 Adobe Illustrator 可编辑 SVG。保留科学内容、构图和配色，文字可直接修改，关键箭头独立编辑，插画尽量转换为矢量路径。请提供高清 PNG 和简短编辑说明。我已选择 GPT-6 astra + High。

**只有参照图，需要改绘：**

> 使用 $scientific-graphical-abstract，根据附件参照图和下面的摘要重新绘制科研机制图，再转换为可编辑 SVG，并写一段英文图注。参照图仅用于风格，科学内容以摘要为准；减少过度高光、重复结论和模板感。我已选择 GPT-6 astra + High。摘要：……

最后一句仅在实际完成模型设置后使用。GPT-6 astra 是执行分析与转换的模型，不是图像生成工具的版本；无法核验具体图像模型时，交付记录应注明。

## 会收到什么

默认包含可编辑 SVG、高清 PNG、编辑说明及质量检查记录。需要时可增加图注、独立背景或期刊 ToC 精简版。

文字和主要箭头可独立修改；插画通常是彩色描摹路径，不等于逐个细胞都有原生语义图层。照片、复杂纹理可能需要保留位图，并明确标注。只有实际在 Illustrator 内另存过，才称为原生 `.ai`；高清预览也不能代替可编辑源文件。

## 安装

解压本包，把其中的 **scientific-graphical-abstract** 整个文件夹放入 Codex 的 skills 目录（通常为 `~/.codex/skills/`；自定义环境以 `$CODEX_HOME/skills/` 为准）。若已有同名 skill，先将旧文件夹备份到 skills 目录之外，再放入新版。重新加载 skill 列表或新开聊天后调用 `$scientific-graphical-abstract`。

本包包含改良版 skill 和本说明；不会自动覆盖你已经安装的版本。此次更新主要增加“先有参照图”的入口、直接转换与改绘分流、GPT-6 astra／High 要求，以及膜结构保护、导出裁切和可编辑性检查。
