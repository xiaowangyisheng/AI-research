# Illustrator 可编辑转换

## 路径选择

| 用户需要 | 合适交付 | 必须说明 |
|---|---|---|
| 保留 GPT 图，只改文字/箭头 | 位图插画 + 原生文字/箭头的混合文件 | 插画本身仍是位图 |
| 图形颜色/轮廓也要修改 | 彩色描摹路径 + 重建原生文字/关键箭头 | 不是无损恢复的原始绘图对象 |
| 逐个细胞、材料、通道语义编辑 | 经用户认可的矢量重建 | 构图及画风可能改变 |
| 原生 `.ai` | 在可用 Illustrator 中打开并另存 | 未实际生成时不能以 PDF 改后缀冒充 |

不要把用户的“要可编辑”自动理解为允许重新设计整图。其此前要求 GPT 作图时，优先转换已确认生成版，保持布局。

## 转换策略

1. 检查源图尺寸、文字清晰度、是否只有截图及 UI 边框，保留原文件。
2. 优先使用可用的 Illustrator/Adobe 矢量化或其他专用转换工具。若需要账号授权，说明限制；一次授权失败后，不循环重试，不擅自转为公开上传。可继续本地转换。
3. 本地可用彩色描摹库如 VTracer；确认实际运行环境和参数接口。依赖缺失先检查现有运行时，必要时在隔离目录安装，不改变用户项目依赖或全局配置。
4. 识别文字框和字符串。macOS Vision 或现有 OCR 可以辅助，但每行必须对照图和科学标签表校对。OCR 常把 `scRNA` 大小写、`±`、数字 `1/l`、上下标和箭头识别错误。
5. 从插画底图移除**原有标签本身**并补背景，然后作为原生 `<text>` 重建。不要只在原字上覆盖新字，也不要给所有标签粗暴盖白框。
6. 复杂、关键或被描摹漏掉的箭头单独重建为路径/箭头标记。必须先清理原箭头，避免重影；不能在改线型时丢失或提高证据含义。用户要求统一实线时，可用关系旁明确的 `proposed/predicted` 标注、分区或清晰图例保留待验证性质，不必强制保留某一种线型。无法判断原线型含义时，只澄清相关关系，不阻塞无关编辑。
7. 描摹去字后的插画，使用少量区域/语义组或保持原绘制顺序的连续分组。任意打乱路径层叠会改变遮挡关系；重分组后需重新渲染检查。
8. 组合成标准 SVG：明确 `viewBox`、画板尺寸、唯一 ID、独立插画/连接线/文字组。Arial/Helvetica 等字体保持为文本；特殊上标可用 `<tspan>`，避免缺字符号。

以上是格式转换流程，不是通用照片修图。需要内容或风格实质编辑时，返回对应图像编辑工具，不用描摹脚本悄悄改研究内容。

## 描摹参数与常见失败

参数不能照抄为永久最优值。先检查工具版本与文档/帮助，再选少量候选配置对比。

- 去噪阈值过高：细虚线、膜结构和字母笔画消失。先保护/重建关键箭头。
- 颜色合并过强：细腻渐变变成粗色块。提高精度，但同时检查文件大小和 Illustrator 操作性能。
- 描摹精度过高：数万小路径造成卡顿，且不会恢复原图不存在的结构信息。
- 去字范围太宽：擦掉膜边界或材料纤维；太窄：残字和黑影。逐区域检查，不只看“无报错”。
- 重建曲线和源箭头略有偏差：产生双箭头/灰影。结合颜色及局部走廊定位旧线，再清理；不要固定使用某张图的坐标。
- 原生文本字体指标与 OCR 框不同：可能溢出或重叠。使用实际字体测量定位，不能只按 OCR 高度猜字号。
- 自动描摹的白色/近白色路径会挡住底层背景。背景单独交付，并按背景参考说明处理；不要全局删除所有白色路径。

## QA 与可编辑性声明

运行 `scripts/audit_svg.py`，核对图片嵌入数量、文本数量、图形元素、外部资源、脚本及重复 ID。
“全矢量”至少要求无 `<image>`；但零 `<image>` 不证明文字是原生文本，也不证明有语义图层或已在 Illustrator 测试。

必须渲染 SVG 并查看，检查细虚线、上下标、图层遮挡、去字补底、文字位置和配色。可使用现有 SVG 渲染器；macOS Quick Look 是备选，其缩略图可能有额外空白，不能把预览留白误当原 SVG 画板尺寸。

可用 Illustrator 时，在原生应用检查文字工具编辑、直接选择路径、分组、箭头、缺字体和保存后重开。无 Illustrator 时，明确“已检查结构与渲染，未在 Illustrator 内实测”。

向用户说明：

- **文字**：可直接修改/已转曲/仍在位图内。
- **图形**：独立语义对象/彩色描摹路径/位图。
- **箭头**：哪些独立重建；方向和证据语义是否检查。
- **纹理**：哪些被近似或简化。
- **打开方式**：“文件 → 打开 SVG”，不要仅把整张图作为链接“置入”；可另存 `.ai`。

不要将文件扩展名或“高清”当成可编辑性保证。
